# راهنمای سریع

## 🎁 مهم‌ترین خبر: هیچ کلید API نیاز نیست!

نرم‌افزار به‌طور پیش‌فرض از **هوش مصنوعی رایگان داخلی (g4f)** استفاده می‌کنه. فقط نصب کن و اجرا کن.

---

## ویندوز

۱. Python 3.9 یا بالاتر رو از https://python.org نصب کن (حتماً تیک **Add Python to PATH** رو بزن).

۲. روی `run_windows.bat` دابل‌کلیک کن.

۳. صبر کن تا پیش‌نیازها نصب بشن (فقط بار اول).

۴. (اختیاری) اگر PDF اسکن‌شده داری، Tesseract OCR رو از این لینک نصب کن:
   https://github.com/UB-Mannheim/tesseract/wiki
   در موقع نصب حتماً «Farsi» یا «Persian» رو هم تیک بزن.

## لینوکس / مک

```bash
chmod +x run_linux_mac.sh
./run_linux_mac.sh
```

برای فعال‌سازی OCR:

```bash
# Ubuntu / Debian
sudo apt install tesseract-ocr tesseract-ocr-fas python3-tk

# macOS
brew install tesseract tesseract-lang python-tk
```

## فلوی کاری نمونه

۱. اجرای برنامه → صفحه «بارگذاری PDF»
۲. انتخاب فایل PDF درسی → کلیک روی «استخراج و تفکیک متن»
۳. تنظیم تعداد سوال، سطح دشواری، نوع و خلاقیت
۴. کلیک روی «✨ تولید سوال» — با AI رایگان داخلی خودکار
۵. دادن آزمون → پاسخ‌دهی → پایان و ثبت
۶. مشاهده تحلیل در «داشبورد»

## اگر g4f کار نکرد چی؟

سرویس‌های رایگان g4f گاهی موقتاً قطع می‌شن. راه‌حل:

**گزینه ۱ (توصیه شده):** Ollama محلی نصب کن.
```bash
# نصب Ollama از ollama.com
ollama pull qwen2.5:3b   # مدل کوچک و سریع
ollama serve             # اجرای سرویس
```
بعد در «تنظیمات» نرم‌افزار، سوییچ Ollama رو روشن کن.

**گزینه ۲:** کلید OpenAI شخصی (از https://platform.openai.com/api-keys) رو در «تنظیمات» وارد کن.

**گزینه ۳:** حالت قالبی (آفلاین) — کیفیت پایین‌تر ولی همیشه کار می‌کنه.
