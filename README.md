# آزمون‌ساز هوشمند (Azmoon Saz)

نرم‌افزار دسکتاپ پایتون برای ساخت آزمون هوشمند از فایل‌های PDF درسی.

## ⭐ ویژگی‌های اصلی

- 🎁 **هوش مصنوعی داخلی و رایگان** — بدون نیاز به کلید API! از طریق `g4f` به مدل‌های GPT/Claude/Gemini وصل می‌شه
- 📄 **خواندن PDF** با پشتیبانی از OCR برای PDF اسکن‌شده
- ✂️ **تفکیک خودکار** درسنامه از سوالات
- 🤖 **تولید سوال تألیفی** با تنظیم تعداد، دشواری، نوع و خلاقیت
- 📝 **حالت آزمون** با ذخیره نتایج و تایمر
- 📊 **داشبورد تحلیل**: نقاط ضعف، سوالات پرخطا، پیشنهاد مطالعه
- 💾 **پایگاه داده محلی SQLite**
- 🎨 **رابط کاربری مدرن** با CustomTkinter و پشتیبانی کامل RTL/فارسی

## 🔧 موتورهای هوش مصنوعی (اولویت‌بندی خودکار)

| # | موتور | نیاز به کلید | نصب اضافه | کیفیت |
|---|--------|--------------|-----------|--------|
| 1 | **g4f (پیش‌فرض)** | ❌ ندارد | ❌ ندارد | ⭐⭐⭐⭐ |
| 2 | Ollama محلی | ❌ ندارد | ✅ Ollama | ⭐⭐⭐ |

اگر یکی کار نکرد، به‌طور خودکار سراغ بعدی می‌ره.

## 📦 پیش‌نیازها

- Python 3.9+
- (اختیاری) Tesseract OCR برای PDF اسکن‌شده
  - Windows: [دانلود از UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)
  - macOS: `brew install tesseract tesseract-lang`
  - Linux: `sudo apt install tesseract-ocr tesseract-ocr-fas`

## 🚀 نصب و اجرا

### Windows
```
run_windows.bat  (دابل‌کلیک کن)
```

### macOS / Linux
```bash
chmod +x run_linux_mac.sh
./run_linux_mac.sh
```

اسکریپت‌های بالا به‌طور خودکار پیش‌نیازها رو نصب می‌کنن.

### نصب دستی
```bash
pip install -r requirements.txt
python main.py
```

## 🎯 استفاده

1. **بارگذاری PDF**: روی «انتخاب فایل PDF» کلیک کن و فایل درسی رو انتخاب کن
2. **استخراج و تفکیک**: روی «استخراج و تفکیک متن» کلیک کن
3. **تنظیم پارامترها**: تعداد سوال، دشواری، نوع، خلاقیت
4. **تولید سوال**: روی «✨ تولید سوال» کلیک کن — با AI داخلی خودکار
5. **آزمون**: به سوالات پاسخ بده و ثبت کن
6. **تحلیل**: تو داشبورد نقاط ضعف و پیشنهادها رو ببین

## ⚠️ نکات مهم

### هشدار ۱ — PDF اسکن‌شده
اگر PDF شما اسکن تصویری است (نه متنی)، حتماً Tesseract OCR را نصب کنید، در غیر این صورت متن استخراج نمی‌شود.

### هشدار ۲ — تکراری شدن سوالات
در تولیدهای مکرر روی همان متن، پارامتر «خلاقیت» را بالا ببرید (0.8-1.0) تا سوالات تکراری نشوند.

### نکته درباره g4f
- g4f به سرویس‌های رایگان وصل می‌شه که ممکنه گاهی موقتاً از دسترس خارج بشن.
- اگر یک سرویس کار نکرد، خودکار سراغ سرویس بعدی می‌ره.
- برای پایداری بیشتر، می‌تونی از Ollama محلی یا کلید OpenAI شخصی استفاده کنی.
